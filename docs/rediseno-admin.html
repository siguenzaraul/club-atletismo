Propuesta de rediseño

Un sistema visual único, moderno y escalable para gestionar el club.

Hoy cada pantalla lleva sus propias clases sueltas, sin componentes reutilizables ni escala de espaciado o sombra. Esta propuesta unifica todo en un sistema de diseño, moderniza las cuatro superficies (gestión, socio, panel y web) y permite al club recolorar y rebrandear sin tocar código.

Fundamento

6 · Sistema de diseño · shadcn/ui + TanStack

Todo lo anterior se sostiene sobre una sola base: shadcn/ui (componentes sobre Tailwind, tematizables por variables CSS) con TanStack Table para las tablas, teñido con la paleta ABTR. Se define una vez y se usa en las zonas de app; la web pública conserva su identidad de marca.

🧩
Se instala con shadcn init (compatible con tu Tailwind v4 + React 19 + Next 15). Mapeamos --primary→azul, --destructive→rojo, --ring→azul… así la marca configurable (sección 7) re-tiñe todos los componentes de una. La DataTable es TanStack: paginación, orden, filtros y columnas configurables sin construirlo a mano.

Configurable por el club

7 · Marca editable sin código

Desde Ajustes del sitio, el club podrá subir su logo (ya existe) y elegir sus colores. El sistema los inyecta como variables CSS al cargar, así que el cambio se refleja en toda la web y en las zonas de gestión y socio — sin que nadie toque el código.
